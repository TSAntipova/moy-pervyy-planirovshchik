# Планировщик обращений арендаторов

Планировщик помогает фиксировать обращения, видеть, кому они переданы, и следить за сроками ответа. Страница рассчитана прежде всего на работу с компьютера.

## Карточка обращения

Каждое обращение содержит название арендатора, дату поступления, описание вопроса, планируемую дату ответа, имя сотрудника или название подразделения, которому передали обращение, текущий этап и приоритет. Название арендатора вводится прямо в карточке. У приоритета три уровня: «Высокий», «Обычный» и «Низкий». Новое обращение получает обычный приоритет, который можно изменить вручную.

Новое обращение получает этап «Новое». Дальше в карточке можно менять данные и этап: «Новое» → «В работе» → «Ожидает ответа» → «Закрыто». Сохраняется только текущее состояние карточки. Закрытые обращения автоматически переходят в отдельный архив и исключаются из списков сроков.

## Главный экран

- **План на неделю** показывает открытые обращения со сроком ответа с понедельника по воскресенье выбранной недели. При открытии страницы показывается текущая неделя.
- **Просроченные** показывает открытые обращения, срок ответа по которым истёк до сегодняшнего дня. Обращение со сроком на сегодня ещё не считается просроченным.
- **Ближайшие сроки** показывает открытые обращения со сроком от сегодняшнего дня до конца следующих шести дней. Карточка может одновременно отображаться в плане недели и в ближайших сроках.
- **Все открытые** даёт доступ к обращениям за пределами недельного плана.
- **Архив** содержит закрытые обращения.

Над недельным планом отображаются даты начала и конца выбранной недели. Стрелки переключают недели, кнопка «Текущая неделя» возвращает к сегодняшней неделе, а календарь открывает неделю, в которую попадает выбранная дата. Списки просроченных и ближайших сроков остаются привязанными к сегодняшнему дню при любом переключении недели.

Даты определяются по местному календарю устройства. Для первой версии предусмотрен поиск по названию арендатора и тексту описания, а в списке открытых обращений — фильтр по этапу. Открытые обращения также можно фильтровать по приоритету.

## Сортировка

По умолчанию недельный план показывает обращения по возрастанию срока ответа, а список просроченных начинается с самого давнего срока. В обоих списках можно поменять порядок сортировки прямо на странице. В первой версии доступны сортировка по сроку ответа в обе стороны и сортировка от высокого приоритета к низкому. При одинаковом приоритете первым показывается обращение с более ранним сроком.

## Доступ по ссылке и хранение

Страница состоит из трёх файлов: `index.html`, `style.css` и `script.js`. Чтобы коллеги могли открыть её по ссылке, файлы размещаются на статическом хостинге. Для работы с обращениями достаточно браузера. База данных, серверная логика и учётные записи не требуются.

Карточки сохраняются в `localStorage` и остаются доступными после перезагрузки страницы в том же профиле браузера по тому же адресу сайта. Каждый коллега видит собственный набор карточек. Общая ссылка открывает одну и ту же страницу, но изменения между браузерами не синхронизируются. Если коллегам нужен единый журнал с одновременным редактированием, потребуется общее хранилище за рамками этой концепции.

## Резервная копия

Кнопка «Скачать копию» выгружает все обращения, включая архив, в файл JSON. Кнопка «Восстановить из файла» позволяет перенести снимок в другой браузер или вернуть данные после очистки хранилища. Перед восстановлением планировщик проверяет файл и запрашивает подтверждение замены текущих данных. При ошибке текущие данные сохраняются. Копию можно передать коллеге вручную.
