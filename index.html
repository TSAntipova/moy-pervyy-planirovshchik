Обращения арендаторов

Как пользоваться журналом

Создайте обращение, укажите арендатора и опишите вопрос. Если срок уже известен, укажите его, чтобы обращение появилось в плане. Меняйте этап по мере работы. Закрытые обращения находятся в архиве.

Журнал хранится в этом профиле браузера по текущему адресу. Для правок используйте одну вкладку. Очистка данных сайта или потеря профиля может уничтожить записи, внесённые после последней копии.

Скачивайте копию после существенных изменений и перед восстановлением. Чтобы перенести журнал, откройте «Восстановить из файла», выберите JSON и подтвердите замену. Для просмотра чужой копии используйте отдельный профиль или сначала скачайте свой журнал. Если нужен общий актуальный снимок для просмотра, договоритесь, кто ведёт исходный журнал.
